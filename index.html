How it works

Four workflow modes. Auto-detected.

The Assistant reads your project state and switches between modes — surfacing exactly the tools you need at this moment of the project.

Setup

New project, fresh start

Create levels with sheets, clone a Project Browser organisation from a template, sync View Templates, sanity-check shared coordinates.

Design

Massing & spaces

Export rooms to Roominess, run client-side daylight analysis, edit room parameters in the browser, push edits back to Revit.

Coordination

Linked-model awareness

Create per-level coordination 3D views, run solid-solid clash detection, place wall sleeves where MEP crosses walls, export NWC for Navisworks.

Documentation

Sheets, schedules, deliverables

Dissociate dimensions safely, transfer sheets between projects, round-trip rooms / templates / object styles through Excel with diff preview.
