Features

Your template's browser,
in every project

Browser Clone reads the source project's active browser organisation and recreates the entire folder hierarchy in the target — with all the plumbing handled automatically.

🗂️

Organisation Definition

Copies the browser organisation element itself — including all grouping levels and sorting rules. If the target already has a matching org, it's reused automatically.

🔗

Shared Parameters

Custom grouping parameters (shared or project) are created in the target and bound to the Views category — matched by GUID for shared params, by name for project params.

🎨

View Templates

Any view templates referenced by seed views are transferred automatically. Existing templates with the same name are reused — no duplicates.

🌱

Seed Views

One lightweight "ZZ Seed" view is placed in every leaf folder so the browser tree appears immediately. Folders that already contain real views are skipped.

📐

View Type Resolution

View family types are matched by name or duplicated from the source. Floor Plans, Ceiling Plans, Structural Plans, 3D, and Drafting views are all supported.

🔄

Safe Re-run

Running again cleans up old seed views first, then recreates them. Real views you've added to the target are never touched — only "ZZ Seed" views are managed.
