Features

Detect, visualise, resolve.

ClashView combines Revit-native clash detection with a browser-based 3D dashboard that makes clash review accessible to anyone on the team, then round-trips a saved shortlist back to Revit as per-clash section-box views.

🎯

Set 1 / Set 2 Picker

Choose host or linked model categories for each set. Discipline presets (Arch, Struct, MEP) for quick setup. Live element counts.

🔴

Solid-Solid Detection

Real geometry intersection, not bounding box overlap. Uses Revit's spatial index for performance. Handles angled and diagonal MEP runs accurately.

🌐

3D Web Viewer

Click any clash to zoom in. Red spheres for hard clashes, amber for clearance. Blue and orange wireframe bboxes show the conflicting elements.

📊

Analytics Dashboard

Severity donut chart, clashes by level bar chart, clashes by category pair breakdown. Summary cards with totals at a glance.

📋

Sortable Clash List

Sort by ID, severity, level, or category. Expand any row to see full element details, dimensions, and clash point coordinates.

🏗️

Level Planes

Transparent level planes with labels give spatial context. Filter by level to focus on one floor at a time.

How it works

Four steps. No Navisworks.

01

Configure

Open the clash setup from the Assistant panel. Pick host vs linked model categories for Set 1 and Set 2. Fittings auto-include with their parent runs.

02

Detect

ClashView runs solid-solid intersection tests across all selected elements. Optional view-scope filter narrows the test to a section box.

03

Review

Results open in the 3D dashboard — opaque building with clashes as red dots. Click a clash, the full MEP run lights up, rest fades to context.

04

Round-trip

Star the clashes you want to fix, export saved.json, and the Assistant creates one 3D view per clash with a tight section box — ready to resolve in Revit.
