Features

Context-aware, not chat-based.

The Assistant monitors your active view, selection, linked models, and document state — then surfaces the right tool automatically. No typing, no conversation.

🎯

Contextual Suggestions

Select dimensions — it suggests dissociation. Load a linked MEP model — it suggests wall sleeves. Open two projects — it suggests browser cloning.

🏥

Model Health Tab

Flags unpinned datums and links, empty worksets, and linked models not using shared coordinates — with clear explanations and one-click fixes.

🖱️

One-Click Execution

Every suggestion has a Run button. Click it and the tool executes with smart defaults — no dialogs to configure unless needed.

📐

Coordination Views

Creates per-level 3D views with section boxes and all links visible — ready for NWC export and Navisworks clash detection.

📤

NWC Export

Batch-exports 3D views (including linked models) to NWC format. Coordination views are pre-checked for one-click export.

🔔

Always Listening

Subscribes to Revit events — document open, view change, selection, idling. Suggestions refresh instantly as your context changes.
